🧠 Two valid ways to handle DB config
✅ Approach 1 (what YOU are using) — Full URL
DATABASE_URL=postgresql://user:password@host:5432/dbname

👉 Everything in one variable

✔ Pros:
Simple (best for beginners)
Works directly with Prisma
Less setup in ECS
✅ Approach 2 (tutorial style) — Split variables
DB_HOST=...
DB_USER=...
DB_PASSWORD=...
DB_NAME=...

Then in code:

const DATABASE_URL = `postgresql://${DB_USER}:${DB_PASSWORD}@${DB_HOST}:5432/${DB_NAME}`;
🤔 Why tutorials use split variables?

👉 Because it’s more flexible & secure in large systems

Benefits:
Rotate password without touching full URL
Share host across services
Easier secrets management

It authorizes the ECS and Fargate infrastructure agents to perform backend operational tasks on your behalf.

Specifically, it is used to:
Pull images: Download container images from Amazon Elastic Container Registry (ECR).

Inject secrets: Retrieve sensitive data from AWS Secrets Manager or Systems Manager Parameter Store.
